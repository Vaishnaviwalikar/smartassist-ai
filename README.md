# 🤖 SmartAssist AI

> **Intelligent Context-Aware Chatbot using Machine Learning, Gemini API, FastAPI, React.js, and Supabase**
>
---

## 🎯 Overview

SmartAssist AI is a full-stack AI chatbot that combines **Machine Learning** and **Generative AI**:

1. A **TF-IDF + Logistic Regression** ML model classifies the user's question into a topic category.
2. A **TextBlob** NLP model performs real-time sentiment analysis.
3. The optimized prompt (with category context + conversation history) is sent to **Google Gemini API**.
4. The response is stored in **Supabase PostgreSQL** with full chat history.

---


## ✨ Features

- 🔐 **JWT Authentication** — Signup, Login, Protected routes
- 🧠 **ML Question Classifier** — 5 categories: Technology, Education, Health, Finance, General
- 💬 **Context-Aware Chat** — Full conversation memory injected into Gemini prompts
- 😊 **Sentiment Analysis** — Positive / Negative / Neutral detection per message
- 🏷️ **Smart Chat Titles** — Auto-generated by Gemini from the first message
- 📊 **Analytics Dashboard** — Sentiment & category breakdowns, most active users
- 🎤 **Voice Input** — Web Speech API (Chrome/Edge)
- 🔊 **Text-to-Speech** — AI responses read aloud
- 📎 **File Upload** — Upload PDF / DOCX → AI summarization
- ⬇️ **Chat Export** — Download session as .txt
- 🌙 **Dark / Light Mode** — Persisted in localStorage
- 📱 **Responsive** — Mobile-first layout with slide-in sidebar

## ⚙️ Setup & Installation

### 1. Database — Supabase

1. Go to [supabase.com](https://supabase.com) → your project.
2. Open **SQL Editor** → paste the contents of `backend/database/schema.sql` → **Run**.

### 2. Backend

```bash
cd backend

# Create virtual environment
python -m venv venv
venv\Scripts\activate       # Windows
# source venv/bin/activate  # Mac/Linux

# Install dependencies
pip install -r requirements.txt

# Download TextBlob corpora (first time only)
python -c "import nltk; nltk.download('punkt'); nltk.download('averaged_perceptron_tagger')"

# Run server
uvicorn app.main:app --reload --port 8000
```

### 3. Frontend

```bash
cd frontend
npm install
npm run dev
```

### 4. Run Both Together (root)

```bash
npm install          # installs concurrently
npm run dev          # starts both backend + frontend
```

## 🧠 ML Model Explanation

The classifier uses a **scikit-learn Pipeline**:

```
Text Input
    │
    ▼
TF-IDF Vectorizer (ngram_range=(1,2), max_features=5000)
    │ Converts text to numeric feature vectors
    ▼
Logistic Regression (C=5.0, max_iter=300)
    │ Multi-class classification
    ▼
Category + Confidence Score
    │
    ▼
System Prompt Injection → Gemini API
```

**Categories:** Technology | Education | Health | Finance | General

Each category gets a specialized system prompt suffix that makes Gemini respond as an expert in that domain.
